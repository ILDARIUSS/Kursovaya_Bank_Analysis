# 📊 Курсовая работа: Анализ банковских операций

Этот проект анализирует банковские транзакции, формирует отчёты по тратам и предоставляет данные о курсах валют и акциях.

## 📌 Функциональность
- Генерация главной страницы (`generate_main_page`)
- Анализ трат по дням недели (`generate_reports`)
- Фильтрация и обработка транзакций (`process_transactions`)
- Получение курсов валют и стоимости акций (`external_api.py`)
